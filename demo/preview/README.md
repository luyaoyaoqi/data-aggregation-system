# UI 风格预览 · 数据采集系统后台

## 启动方式

**直接双击 `board.html` 在浏览器打开即可**（file:// 协议，无需启动任何服务，无需 npm install）。

也可以单独打开任何一个 `d1.html` / `d2.html` / `d3.html` / `d4.html` 查看单个风格。

## 文件清单

| 文件 | 风格 | 关键特征 |
| --- | --- | --- |
| `d1.html` | 国产稳健升级 | 深蓝顶栏、卡片 1px 边框、信息密度中等，最贴近原型 |
| `d2.html` | Tally 极简现代 | 白底顶栏、大留白、字号偏大、无边框、输入框底划线 |
| `d3.html` | 稳健+极简混合 ⭐ 推荐 | 白底顶栏 + 无边框卡片 + hover 阴影，三层阴影体系 |
| `d4.html` | 深色模式差异化 | 近黑底 + 深灰卡片 + 亮蓝强调，差异化最大 |
| `board.html` | 4 风格对比页 | 4 个 iframe 并排（≥1600px 屏 4 列，否则 2 列） |

## 技术约束

- 纯 HTML + CSS，**不引** 任何框架（无 Vue/React/Tailwind/Bootstrap）
- **不引** 任何 JS（board 页只用 iframe）
- 字体：Inter via Google Fonts CDN
- 颜色 / 圆角 / 阴影 / 间距 全部用 CSS 变量集中在 `:root`
- 单文件 ≤ 400 行
- 关键尺寸：顶部 56px / 左侧 240px / 右侧 320px / 底部 56px，4 个风格保持一致

## 推荐选择

**D3** —— 既现代又稳重，最适合 B 端表单编辑器场景：
- 白底顶栏比 D1 的深蓝更国际化
- 比 D2 更紧凑、信息密度更高（chip 用 2 列网格而不是单列）
- 三层阴影（card / hover / modal）层级清晰
- 8px 圆角折中 D1（8px）和 D2（10px）

如果产品定位偏稳重保守 → 选 **D1**。
如果追求极简国际化 → 选 **D2**。
如果面向开发者 / 高端感 → 可选 **D4**。
